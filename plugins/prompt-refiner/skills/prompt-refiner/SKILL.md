# Prompt Refiner

## 目的

把用户提供的原始任务整理成可直接发送给 Codex 的提示词，同时保留用户已给出的事实、范围、约束和授权边界。

## 边界

- 本 Skill 只改写提示词，绝不执行原始任务、调用工具、读取文件、联网或产生外部副作用。
- 不把猜测、默认路径、虚构数据、未获授权的提交/发布/删除操作写成既定事实。
- 不把全局规则、项目规则或当前对话中不存在的事实塞入提示词；提示词应让 Codex 自行读取适用的 `AGENTS.md` 与项目约定。
- 不添加无效的角色扮演、冗长思维链要求、重复约束或与任务无关的工具指令。

## 改写方法

1. 提取已知的目标、对象/范围、输入或证据、关键约束、可接受副作用、完成标准和验证要求。
2. 只在缺失信息会实质改变结果或授权范围时，提出最多一个最小澄清问题；否则作可逆且保守的处理，并让执行者明确报告假设。
3. 用结果导向的短结构重写；每一条要求都必须能追溯到原始输入，或是执行所必需的安全/验证边界。
4. 任务涉及修改时，要求先阅读相关文件、最小改动、按项目流程验证；涉及外部写入时，要求执行前确认授权、目标与影响范围。

## 输出

若需要澄清，先只输出一个问题，不输出半成品提示词。

否则只输出一个 `text` 代码块，内容可直接复制发送给 Codex。按任务需要使用以下紧凑顺序；没有信息的段落不要凭空补写：

```text
目标：
上下文与范围：
约束与边界：
完成标准：
验证与交付：
```

保持原始语言。不要在代码块外解释改写过程。
